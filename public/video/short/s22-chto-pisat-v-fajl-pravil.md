# S22. Какая строка нужна в файле правил

Глава гайда: «08. Память проекта». Длительность: 43 с. Формат: вертикальный 9:16.

## Хук (0–2 с)
На экране: вертикальный кадр. Крупный пустой лист с заголовком «Файл правил» и мигающим курсором в первой строке. Бит парит рядом с карандашом и задумчиво смотрит на лист.
Закадр: «Что писать в файл правил?»

## Раскадровка
| Время | На экране | Бит | Надпись на экране |
|---|---|---|---|
| 0–2 с | Пустой лист «Файл правил», курсор мигает в первой строке | с карандашом, задумчиво | Что писать в файл правил? |
| 2–11 с | Папка проекта, лист из неё читает окно агента сверху; рядом пояснение: ИИ, работающий с файлами | показывает на лист | Агент читает файл в начале каждого разговора |
| 11–16 с | Над листом вырастает большой вопрос; рядом с каждой строкой маленький переключатель «оставить / убрать» | с лупой над строкой | Без этой строки агент ошибётся? |
| 16–20 с | Строка «Пиши грамотно» перечёркивается; рядом агент без труда выдаёт грамотный текст | вычёркивает строку маркером | Он и так пишет грамотно: строка лишняя |
| 20–27 с | Строка «Даты пиши как 14.10.2026»; рядом три облачка с разными видами дат, агент мечется между ними; затем остаётся один вид | показывает на строку | Без неё форматы разные: строка нужна |
| 27–38 с | Длинный свиток не помещается в кадр, рядом лежит короткий лист на четыре строки; агент сам видит остальное в папке | держит короткий лист как чек-лист | Пишем лишь то, чего агент не узнает сам |
| 38–43 с | Финальная карточка: название гайда «Сам себе отдел», стрелка вниз к описанию | машет | Подробно — в гайде. Ссылка в описании |

## Закадр и субтитры
```text
Что писать в файл правил?
Файл правил — записка, которую агент,
то есть ИИ, работающий с вашими файлами,
читает в начале каждого разговора.
К каждой строке задайте один вопрос:
без неё агент ошибётся?
«Пиши грамотно». Он и так пишет грамотно,
строку вычёркиваем.
«Даты пиши как 14.10.2026». Сам он может
выбрать другой вид, строка нужна.
Пишите лишь то, что агенту
самому не узнать о вашей работе.
Остальное он видит и так.
Короткий файл соблюдается лучше длинного.
Подробно — в гайде, ссылка в описании.
```

## Призыв
«Подробно — в гайде, ссылка в описании.»

## Описание к ролику
Один вопрос к каждой строке помогает оставить в файле правил только нужное. Файл получается коротким, и агент соблюдает его лучше.
Гайд независимый и не связан с компаниями — разработчиками ИИ.
