# S38. Два помощника — один сайт

Глава гайда: «13. Команда агентов». Длительность: 41 с. Формат: вертикальный 9:16.

## Хук (0–2 с)
На экране: вертикальный кадр, экран разделён пополам. Сверху страница сайта в тёплых цветах, снизу страница в строгих, будто с другого сайта. Бит чешет антенну.
Закадр: «Две страницы — будто с разных сайтов.»

## Раскадровка
| Время | На экране | Бит | Надпись на экране |
|---|---|---|---|
| 0–2 с | Две страницы одного сайта: сверху тёплая, снизу строгая | чешет антенну | Две страницы — как с разных сайтов |
| 2–10 с | Учебный пример: Олег ставит задачу двум помощникам, у каждого свой стол и своё окно; рядом пояснение: два ИИ, работающих с файлами | работает в команде: главный Бит и два помощника | Учебный пример: Олег, две страницы сайта |
| 10–15 с | На одной странице «Привет! Смотрите, как бывает», на другой «Рады предложить вам услуги» | разводит руками | Один на «ты», другой на «вы» |
| 15–20 с | Стеклянная перегородка между помощниками, каждый уверенно решает своё | с лупой | Они не знают друг о друге |
| 20–29 с | Общий файл «тон и обращение» лежит в центре стола; оба тянутся к нему; печать «правит только хозяин» | кладёт файл на стол | Общие решения — в один файл. Править можете только вы |
| 29–35 с | У каждого помощника своя папка с табличкой; чужие правки не затирают друг друга | ставит таблички на папки | У каждого своя папка |
| 35–41 с | Финальная карточка: название гайда «Сам себе отдел», стрелка вниз к описанию | машет | Подробно — в гайде. Ссылка в описании |

## Закадр и субтитры
```text
Две страницы — будто с разных сайтов.
Олег поручил двум агентам, то есть ИИ,
работающим с файлами, написать
по странице.
Один написал тепло и на «ты»,
другой деловито и на «вы».
Они не знают друг о друге
и каждый решает по-своему.
Общее для всех, как тон и обращение,
впишите в общий файл и дайте обоим.
Править его можете только вы.
И у каждого пусть будет своя папка,
чтобы не затирать чужие правки.
Подробно — в гайде, ссылка в описании.
```

## Призыв
«Подробно — в гайде, ссылка в описании.»

## Описание к ролику
Как сделать так, чтобы страницы одного сайта, написанные разными помощниками, выглядели единым целым.
Гайд независимый и не связан с компаниями — разработчиками ИИ.
