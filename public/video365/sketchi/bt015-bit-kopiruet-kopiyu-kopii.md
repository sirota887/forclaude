# BT015. Бит копирует копию копии

| Поле | Значение |
|---|---|
| Формат | Скетч «Бит против Турбо» |
| Длительность | 47 с |
| Кадр | вертикальный 9:16 |
| Глава гайда | 04 |
| Персонажи | Бит, Турбо, Олег |
| Урок | Копия должна соответствовать задаче: скопируйте рабочую папку, проверьте, что из копии можно восстановиться, и начинайте. |
| Основа | — |
| Источник | — |

## Хук (0–2 с)
На экране: полоса прогресса «Копирование: осталось 2 ч 58 мин». Олег с остывшей кружкой смотрит на неё, над двумя внешними дисками парит Бит.
Реплика: «Бит, я просил переименовать три файла. Три!»

## Реплики
**ОЛЕГ:** Бит, я просил переименовать три файла. Три!
**БИТ:** Всё по правилам! Сначала копия всего диска. Потом проверка копии. Потом копия копии на второй диск.
**ОЛЕГ:** И сколько это займёт?
**БИТ:** Три часа. Зато надёжно!
*(Ремарка: полоса прогресса еле ползёт. Мимо проплывает Турбо с горячей чашкой, на его экране «Готово: 3 файла».)*
**ТУРБО:** Скопировал рабочую папку, достал из копии один файл — открылся. Тогда переименовал. Чай ещё горячий.
**БИТ:** Но у меня целых два уровня защиты!
**ОЛЕГ:** Бит, мой чай остыл. Для трёх файлов хватит копии одной папки.
**БИТ:** Значит, размер копии выбираем по размеру задачи.
**ОЛЕГ:** Копируем рабочую папку, проверяем, что из копии можно достать файл, и начинаем.
*(Ремарка: Бит нажимает «Отмена», полоса прогресса исчезает, и он провожает её печальным взглядом.)*
**БИТ:** Отменяю копию копии. Хотя прогресс был такой красивый.
**ТУРБО:** Чай всё ещё горячий.
