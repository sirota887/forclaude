# Задание: 365 сценариев роликов (по одному на каждый день года)

Работай в своей ветке, по правилам CLOUD-TASKS.md, субагенты на Sonnet. Результат открыто в `public/video365/` (публичный контент; платные тексты не цитировать дословно). Уже написанные 60+12 сценариев используй и переработай, где подходят.

## Персонажи (внешность для раскадровки)
- **Бит** — аккуратный агент: капсула тёплого оранжево-терракотового цвета, тёмный визор с двумя огоньками, антенна, парит без ног. Всегда уточняет и проверяет, иногда до занудства.
- **Турбо** — соперник, сверхбыстрый агент: синий угловатый «болид» с полосами скорости. Делает всё мгновенно и иногда катастрофично.
- **Олег** — фотограф-фрилансер, их начальник. **Аня** — дизайнер интерьеров, скептик.
- В репликах можно называть реальные инструменты описательно (Claude Code, Codex и др. как самые популярные агенты), но персонажи наши, без чужих логотипов и маскотов. В описании каждого ролика: «Канал не связан с разработчиками упомянутых сервисов». Без обещаний дохода и способов обхода блокировок.

## Состав (365)
1. Сериал «Сам себе отдел» — 52 серии по 60–90 с (воскресенья), 4 сезона по 13 серий, сквозной сюжет, крючок в конце каждой серии; сначала библия сериала (персонажи, арки сезонов).
2. 104 скетча «Бит против Турбо» (30–60 с): смешная ситуация → урок.
3. 104 ролика «приём/факт» (20–45 с): только проверяемые факты; без интернета — только из `research/` в guide-src, источник в `sources.csv`.
4. 52 объяснялки по главам гайда (45–60 с).
5. 53 «слово дня» из словаря гайда (15–25 с).

## Формат каждого файла
Формат, хук в первые 2 секунды, реплики с персонажами, раскадровка (что на экране), субтитры, длительность, заголовок и описание для YouTube / VK Клипов / RuTube / TikTok (до 150 символов + хэштеги), призыв «гайд "Сам себе отдел" — ссылка в описании».
Плюс `index.csv` и `schedule.csv` на 365 дней с 2026-11-09 (чередуй форматы). Коммит и push партиями по ~50 файлов. В конце допиши отчёт в CLOUD-TASKS.md (только числа).
